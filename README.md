# FunBid

FunBid is an online auction platform where users can browse auction products and place bids.

## Features

- User registration and login
- Browse auction products
- Place bids
- Auction management
- Bid management
- Image upload
- AI-powered suggestions

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Sequelize
- PostgreSQL

### Other Technologies
- JWT
- ImageKit
- Google Gemini AI

## Project Structure

The project consists of two applications:

- **CMS** — Used by admins to manage auction products, auction status, and bids.
- **Public Website** — Used by users to browse auctions and participate in bidding.

## Team Project
